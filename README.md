## 🛠️ Core Engineering Highlights

- **Autonomous Line Following Robot:** Embedded bare-metal C/C++ firmware running on ATMega328P with a 5-channel TCRT5000 infrared reflectance sensor array and closed-loop differential PWM motor control.
- **AI Automation & Pipelines:** Event-driven multi-node workflows built with n8n, integrating Google Gemini and OpenAI APIs, typed schema validations, and webhook dispatching.
- **Academic Foundation:** Rigorous computer science scholarship via Harvard University's CS50 and advanced STEM coursework at Afajuddin Memorial School and College.
- **Interactive Neural Particle Lattice:** Canvas rendering real-time physics and mouse proximity reactions.
- **Differential Steering Simulator:** Live in-browser sensor telemetry simulator demonstrating motor PWM responses.
